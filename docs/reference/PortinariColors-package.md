# PortinariColors: color palettes inspired by Candido Portinari

Discrete and continuous color palettes inspired by paintings of Candido
Portinari (MASP collection and the UN 'Guerra' and 'Paz' panels):
qualitative, diverging and sequential palettes, with `ggplot2` color and
fill scales and a colorblind-safety check.
